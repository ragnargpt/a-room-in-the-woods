# Changelog

## 0.1.0 — 2026-09-20

First public creation kit.

- English-first repository with a Chinese guide and bilingual local studio.
- Photo-first onboarding, a confirmed-layout gate, material close-up guidance and a room-to-woodland route for Codex.
- Editable Blender room scaffold and original woodland library; browser-ready compressed GLB assets and a temporary invented example.
- Geographic sun/moon, daylight-saving-aware civil time, illustrated sunset lighting, moving lake and reflected landscape.
- Individual object visibility/focus and optional camping/lakeside objects.
- Opt-in original forest, water, campfire and night ambience; pauseable visual movement.
- Local content-addressed versions, checksum-verified recovery and safe staged model builds.
- Automated workflow checks, license notices, asset provenance and a public-file-only release packager.
